# Pixel Forge · UI 与关间换装优化

本轮围绕三项体验调整：让主要操作更容易找到、明确每关都能换武器、让燃过的草地继续造成可见伤害。以下记录对应当前 Demo 实现。

## 选武器，再出发

首胜教学仍包含绘画、火剑战斗、森林恢复和回旋器试用。试用结束的主按钮改为“选把武器再出发”，进入武器库选择第二关装备。武器库用“每关结束，都能换武器”说明规则，首次要求点一次武器卡片；点选后立即装备主武器，显示“出战中”和装备反馈，开放出发按钮。选择已经装备的回旋器也能完成这一步，原来的火剑一直保留。

首次强提示的条件是 `onboarding.loadoutLessonPending && !onboarding.loadoutLearned`。只有刚完成教程进入武器库时才设置 `loadoutLessonPending`；点选主武器后保存 `loadoutLearned`。刷新可恢复尚未完成的提示，完成后不再要求重复点选。已有存档不会补设首次强提示，仍可看到常规换装说明。

第二关起，常规通关先展示本次解锁并选择强化；领取后推进关号、清除本关进行中状态，直接进入武器库。下一关地图、主备装备与出发按钮在同一页，不再增加“继续／选择其他武器”的关间弹窗。之后每关可直接沿用当前武器，也可点卡片换装；第 10 关保留通关展示。

Lv.4 解锁备用槽，点备用槽即可更换或创建备用武器。点武器卡片始终设置主武器；点击当前备用的卡片时，主备位置交换。战斗中仍通过 Q 或触屏按钮切换。工坊保存只更新作品并返回武器库，不自动改变主备位置。

## 减少同时显示的文字

- 武器库突出武器卡、当前装备和出发。地图使用短提示；武器详情与改造、冒险进度默认折叠。
- 工坊按“画图案 → 试攻击 → 保存武器”组织操作。攻击风格用短标签说明取舍，元素比例和配方生效条件直接呈现；攻击数值、握持／发射点微调按需展开。
- 手机按地图、武器卡、装备的顺序展示，出发栏固定在底部；工坊的返回、保存和草稿状态同样固定在底部，保留底部安全区。

## 草火与余烬

每块草地独立计时，强度沿用点燃时的火元素占比；蔓延到相邻草地时继承该强度。

| 地块状态 | 持续时间 | 对站在地块上的敌人造成的伤害 |
|---|---|---|
| 明火 | 3 秒 | 每秒 `4 × 火占比`，期间可向相邻草地蔓延 |
| 余烬 | 4 秒 | 每秒 `2 × 火占比`，停止地块直接蔓延 |
| 冷焦土 | 保留到本次场景结束 | 无地面伤害，不能再次点燃 |

例如纯火点燃的草地，明火每秒造成 4 点伤害，余烬每秒造成 2 点。晚到的敌人即使没有武器灼烧状态，踏入余烬也会掉血；多个相邻热地块只取最高伤害，不重复叠加。离开热地或地块冷却后，地面伤害停止；已有的武器灼烧按自身剩余时间继续。草火不伤玩家。

余烬以发亮的炭块和火星区别于冷焦土；敌人接触热地时显示灼烧反馈，地面伤害约每 0.6 秒合并显示一次数字，避免逐帧飘字。

## 验证记录

已运行 `node tests/smoke.cjs`，七组逻辑测试通过。新增地形覆盖包括：明火转余烬、余烬四秒伤害、晚进入地块的敌人受伤、明火与余烬重叠取最高值、离开地块停止地面伤害、冷焦土无伤且不再点燃、玩家不受草火伤害和伤害反馈。原有测试继续覆盖十关战斗与奖励、主备配置、存档恢复与隔离、首胜奖励唯一性、真实教学战斗。

浏览器验收已完成，实际新手操作与测试夹具覆盖分别如下：

- **新档实际流程**：绘画 → 首击 → 草火 → 首胜 → 回旋试用 → 武器库。首次选装待完成时刷新仍保留提示；点击当前回旋器也能确认，完成后刷新不再要求重做；换回火剑后成功进入第二关。
- **存档与装备夹具**：夹具 A 验证奖励刷新恢复、领取后直接进入第三关武器库，再次刷新不重复领取。夹具 B 从只有一把剑的旧4级存档出发，无首次选装限制；完成创建发射器、保存、设为备用、点击卡片交换主备及战斗触控切换。
- **界面检查**：使用满级10件武器库和三元素配方检查390×844手机、1280×800桌面布局，包括固定操作栏与折叠详情；无横向溢出，浏览器错误日志为空。
- **地形 QA 页**：调用正式 `Game`／`Renderer`，观察橙色余烬与暗色冷焦土；纯火余烬上1秒扣2点生命，移出热地或冷却后地面伤害均为0。

以上覆盖功能与界面行为；玩法平衡、后期关卡难度和声音听感仍待用户实际试玩调整。
