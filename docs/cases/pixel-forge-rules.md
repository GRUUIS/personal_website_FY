# 像素造物师 · Pixel Forge V0.5 Demo

用原生 HTML、CSS、JavaScript、Canvas 2D 和 Web Audio 实现的十关小游戏。玩家收藏自己绘制的武器，按地图选装，在战斗中自动攻击、移动、闪避和切换主备武器。

## 启动与测试

在 `PixelForgeDemo` 目录运行：

```sh
node tools/serve.cjs 4176
```

浏览器打开 [本地 Demo](http://127.0.0.1:4176)。无需安装 npm 依赖，不加载 CDN 或外部接口。

逻辑测试入口：

```sh
node tests/smoke.cjs
```

本次已通过七组自动化测试：编辑器、固定武器属性、元素／地形规则、十关战斗与奖励、武器库和存档、新手进度隔离、真实教学战斗。地形测试新增余烬持续伤害、相邻地块不叠伤、离开热地与冷却后停止伤害等覆盖。

浏览器已从新档实际完成绘画、教学战斗、首胜、回旋试用、首次选装与进入第二关，并检查引导刷新恢复。另用测试夹具验证奖励恢复与关间回库、旧档无强制引导、Lv.4 新建备用和主备切换、满级武器库与配方；正式战斗／渲染代码的地形 QA 页确认余烬持续伤害及冷却停止。390×844 手机与1280×800桌面无横向溢出，浏览器错误日志为空。具体覆盖见[本轮验证记录](../docs/PixelForge_UI与关间换装优化_2026-09-09.md#验证记录)；玩法平衡、后期关卡难度和声音听感仍待用户实际试玩调整。

## V0.5 首次体验

新档先进入“失色的森林”，在8×8画布添一笔火红，再使用自己的作品完成真实挥砍和草火教学。首胜先让森林恢复颜色，再解锁保留原图案的回旋器，立即体验往返攻击。试用结束点击“选把武器再出发”进入武器库，按提示点选任意武器后，才能出发挑战第二关；原来的火剑仍保留，回旋器试用也可重复、修改作品。

首次选装强提示只在刚完成教程时触发，点卡片即装备主武器并完成引导。已有存档不强制补做；每次关间仍显示“每关结束，都能换武器”，可换装，也可沿用当前武器直接出发。

顶部“从1级测试”创建独立测试档，“重新测试”只重建测试档，“返回原存档”恢复原进度。旧档不必手动清浏览器数据。保存武器只更新作品，不再强制改变出战主备槽；类型、颜料与工具按解锁逐步显示。

本轮变化见 [UI 与关间换装优化](../docs/PixelForge_UI与关间换装优化_2026-09-09.md)；此前首胜教学实现见 [V0.5交互实现](../docs/PixelForge_Demo_V0.5_新手体验与交互实现.md)。

## 从选装到出战

1. **武器库／关前选装**：查看下一关地图与简短环境提示，点击作品卡片立即装备主武器；当前武器显示“出战中”。武器详情、复制／删除／导出与冒险进度按需展开；Lv.4 起点击备用槽选择第二把武器。
2. **像素工坊**：编辑原画，选择攻击方式、攻击风格与混色配方；攻击数值和外观微调折叠显示，发射器可另画弹丸。保存只更新作品并返回武器库，出战配置通过武器卡片和备用槽调整。
3. **环境试用**：在普通、森林、瀑布三个场景观察固定攻击轨迹和元素效果，再保存并选装。
4. **战斗**：角色自动攻击。点击地面或使用 WASD／方向键移动、空格闪避、Q 切换武器、Esc 暂停；手机使用独立的摇杆、闪避与换装控件。
5. **关间奖励**：首段教学解锁回旋器并引导选装；第二关起的常规通关领取强化后直接回武器库，查看下一关、换装或沿用当前武器，再点击出发；第 10 关通关后保留作品并可导出。

手机端先呈现地图和武器卡片，底部固定显示当前装备与出发按钮；编辑武器时，返回、保存与草稿状态也固定在底部。

常规强化候选不足三项时，使用三种补充强化填补选择：**厚实画纸**（最大生命 +10）、**踏墨轻步**（移动速度 +5%）、**沉着落笔**（直接伤害 +4%），各最多叠加三层。

战斗逻辑场地固定为 960×600；渲染随容器等比适配，手机保留完整战场和攻击预警。每关开始恢复生命，失败可重试并继续使用自己的作品。

## 武器类型、工艺与颜色

**武器的长、宽和面积不影响任何攻击属性。** 轮廓和可见边界仅用于呈现与缩略图缩放；攻击规则读取武器类型、工艺和强化。扩展空白画布不会改变战斗属性。

| 类型 | 解锁 | 固定攻击形式 |
|---|---|---|
| 挥刃 | Lv.1 | 面向目标进行扇形挥砍 |
| 回旋器 | Lv.2 | 旋转飞出并返回，去程与回程分别命中 |
| 发射器 | Lv.4 | 发射直线弹丸，命中首个敌人后消失 |
| 长枪 | Lv.6 | 沿窄长区域突刺，贯穿同一列敌人 |
| 重锤 | Lv.8 | 蓄力后砸击圆形区域，可用闪避取消 |

重锤沿目标方向选取落点，最远 80 个逻辑单位；蓄力开始时锁定目标当前位置，目标超出范围则取最远落点。均衡工艺的砸击半径为 52。

每类武器可选三种工艺：**均衡**为标准规格；**轻巧**以直接伤害换取更快出手；**宽幅**扩大本类攻击覆盖，并付出伤害与出手速度的代价。工艺不由原画像素形状推断。

火、冰、电三种元素按本体可见元素像素的比例分配基础能力。墨黑、米白、木棕属于中性装饰，不计入元素比例分母；中性色也不增加重量或伤害。弹丸原画只改变外观，继承本体的元素能力。

任意对应的两种元素各占至少 25%，即可选装一个混色配方：

| 配方 | 元素 | 附加效果 |
|---|---|---|
| 余烬导线 | 火＋电 | 电弧第一跳附带半强度灼烧 |
| 霜电回路 | 冰＋电 | 电弧第一跳附带半强度减速 |
| 冷热裂纹 | 火＋冰 | 留下短时裂纹，同件武器后续直接伤害提高 |

Lv.4 解锁备用槽；出战携带主武器和备用武器，切换有冷却。已经发出的回旋器与弹丸保留发射时的装备、像素和规则快照，切换武器不会让旧弹体换色或换属性。

## 逐级成长与画稿

- 画布上限：Lv.1 为 8×8，Lv.3 为 12×12，Lv.6 为 16×16，Lv.9 为 24×24。
- 色板从 3 色逐步增加，Lv.5 开放 8 色，Lv.8 开放完整 12 色。
- 已有画稿可继续使用原尺寸；扩展画布时原图居中保留，不自动拉伸或补色。
- 工坊提供画笔、橡皮、填色、吸色、撤销／重做、缩放和平移；镜像／装饰层与框选／批量换色随进度开放。
- 绘画快捷键：B 画笔、E 橡皮、G 填色、I 吸色、H 平移；Ctrl／Cmd+Z 撤销，Ctrl／Cmd+Shift+Z 或 Ctrl／Cmd+Y 重做。聚焦画布后可用方向键移动像素光标，空格落笔。

作品、草稿、出战配置与进度保存在当前浏览器的本地存储中。常规存档继续使用 `pixel-forge-save-v4`，内部版本为5；独立新手测试档使用 `pixel-forge-test-v5`。旧版 `pixel-forge-art-v1` 只有一幅作品，没有关卡进度记录：迁移时保留原画和 16×16 画布，开放工坊 8 级以继续编辑原有颜色，闯关旅程从第 1 关开始。不同浏览器或不同站点地址的存档相互独立。

## 十关地图与地形

| 关卡 | 主题 | 战斗重点 |
|---|---|---|
| 1 | 工坊草地 | 学习原画攻击、移动与闪避 |
| 2–3 | 纸叶森林 | 火点燃连片草丛，石路隔火；明火结束后余烬继续灼烧，冷却后成为安全焦土 |
| 4–5 | 雾瀑河岸 | 湿区使敌人潮湿，增强电弧并削弱灼烧；干路和岩台形成不同作战位置 |
| 6–7 | 回声石窟 | 岩壁形成通道，观察突刺、射击与回旋路线 |
| 8–9 | 旧熔炉 | 集中敌群与狭窄路线，利用重锤蓄力和闪避 |
| 10 | 画册交界 | 草丛、湿区与干区并存，最终首领跨区作战 |

草地依次经历 **明火 3 秒 → 余烬 4 秒 → 冷焦土**。以点燃时的火元素占比为强度，站在明火上的敌人每秒受到 `4 × 火占比` 伤害，余烬为 `2 × 火占比`；多个热地块重叠只取最高伤害，离开地块或地块冷却后停止地面伤害。草火不伤玩家，冷焦土不能再次点燃；地面伤害与敌人身上的武器灼烧独立计算。

六套场景使用本地程序绘制；草丛未燃／明火／余烬／冷焦土、水纹、水雾与岩块直接对应关卡地形。主角、六类普通敌人、两名首领和木桩沿用像素矩阵，并加入程序运动、受击、灼烧、冰缓、潮湿、裂纹、电弧和落锤反馈。

## 声音与素材来源

声音默认关闭，点击页面音符按钮开启。短音效、风叶／鸟鸣、瀑布底噪及其他地图环境音均由本地 Web Audio 代码合成，**没有下载或使用第三方音效录音，也不需要外部音源**。合成环境声不是自然实地录音。

音频覆盖绘画、选择、返回、保存、装备、五类攻击、回旋返手、命中、受伤、闪避、三元素、预警、死亡、失败、胜利和解锁；群攻中重复的同类声音限频。切换地图时环境声平滑过渡，关闭声音或暂停时淡出并释放声音源。音色以正弦／三角波和滤波噪声为主。

本轮场景、地形和战斗特效均为项目内原创绘制代码。已有图标和海报继续保留在 `img/branding/`，附带其原有生成提示词；旧 `img/arena.png` 保留为历史资源，新地形由渲染器绘制。
